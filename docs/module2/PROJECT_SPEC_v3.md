# PROJECT_SPEC v3 — 8주 맞춤 운동 계획 생성 시스템

> 모듈 2 개발 명세의 최종 기준이다. 이전 v2(12주 사다리, 7개 체력요소, 하중비 기반 진단)는 더 이상 따르지 않는다.

본 시스템은 합성 장병 데이터를 기반으로 현재 체력과 목표 체력의 차이를 산출하고, 이를 활용하여 8주 운동 계획을 생성한다. 정량적 목표는 **연령별 체력검정 각 종목의 1급 이상 달성**으로 설정하며, **15kg 군장 훈련 수행을 위한 체력 준비**를 보조 목표로 반영한다.

## 0. 모듈 구성과 담당

| 디렉토리 | 역할 | 담당 |
|---|---|---|
| `backend/module1/` | 합성 데이터 생성, 입력 검증, 목표 상태 설정, 1×4 차이 행렬 산출 | 규택 |
| `backend/module2/` | Claude 기반 8주 운동 계획 생성, 코드 검증, 수정·재검증 | 하진 |
| `frontend/web/` | HTML 기반 입력·결과 화면 | 추후 결정 |

모듈 1과 모듈 2는 **API 계약(1.6절)으로만** 연결된다. 모듈 2는 모듈 1의 코드나 데이터 파일을 읽지 않는다. 목표 기준표는 모듈 1이, 운동 목록·근거표·계획 규칙은 모듈 2가 소유한다.

## 1. 모듈 1: 데이터 검증 및 목표 대비 차이 산출

### 1.1. 목표 기준표

목표 기준표는 국방부 「부대관리훈령」 별표 31의 남군 체력검정 기준을 참조하여 구성한다. 목표 기록은 각 종목에서 1급 이상을 충족하는 경계값으로 설정한다.

| 연령 | 팔굽혀펴기: 2분 | 윗몸일으키기: 2분 | 3km 달리기 |
|---|---|---|---|
| 25세 이하 | 64회 이상 | 78회 이상 | 812초 이내 |
| 26~30세 | 62회 이상 | 76회 이상 | 832초 이내 |
| 31세 이상 | 26~30세 기준을 임시 적용 (`confirm_needed: true`) | | |

현재 기록과 목표 기록에는 동일한 측정 시간 및 수행 방식을 적용한다.

### 1.2. 합성 장병 데이터

실제 개인정보를 사용하지 않고 가상의 장병 데이터를 생성한다.

| 항목 | 처리 방식 |
|---|---|
| 키·체중·나이 | 합성 데이터 생성 |
| BMI | 키와 체중을 이용하여 계산 |
| 성별 | 남성으로 고정 |
| 보직 | 보병 소총수로 고정 |
| 팔굽혀펴기 | 2분간 수행 횟수 생성 |
| 윗몸일으키기 | 2분간 수행 횟수 생성 |
| 3km 달리기 | 소요 시간 생성 (초) |
| 전투하중 | 15kg으로 고정 |

### 1.3. 입력값 검증 및 파생값

필수값 누락, 자료형 오류, 음수, 잘못된 단위 및 측정 조건 불일치를 검증한다. 달리기 시간은 초 단위로 통일한다.

- BMI = 체중(kg) / 키(m)²
- 하중비 = 전투하중(kg) / 체중(kg) = 15 / 체중(kg)

하중비는 **참고 정보**로만 관리하며 목표 기록이나 체력 부족분에 대한 가중치로 사용하지 않는다. 검증에 실패하면 입력 오류를 반환하고 차이 행렬 생성을 중단한다.

### 1.4. 목표 상태 설정

키·체중·BMI·나이·성별·보직·전투하중은 유지하고, 세 체력 기록에 연령별 목표 기준을 적용한다. 이미 목표를 초과한 항목은 현재 기록을 유지한다.

| 항목 | 목표 기록 |
|---|---|
| 팔굽혀펴기 | `max(현재 횟수, 1급 기준 횟수)` |
| 윗몸일으키기 | `max(현재 횟수, 1급 기준 횟수)` |
| 3km 달리기 | `min(현재 시간, 1급 기준 시간)` |

목표 상태는 비교·계획 수립을 위한 목표이며, 8주 후 실제 도달 기록의 예측값이 아니다.

### 1.5. 차이 산출

점수화·정규화는 하지 않는다. 원래 단위를 유지한 채 `Δ = Goal − Now`를 1×4로 산출한다.

열 순서: `[팔굽혀펴기 횟수, 윗몸일으키기 횟수, 3km 소요시간(초), 하중비]`

예시 (23세, 체중 75kg, 현재 48회·60회·960초):

| 구분 | 팔굽혀펴기 | 윗몸일으키기 | 3km(초) | 하중비 |
|---|---|---|---|---|
| Now | 48 | 60 | 960 | 0.20 |
| Goal | 64 | 78 | 812 | 0.20 |
| **Goal − Now** | **16** | **18** | **−148** | **0** |

`max`/`min` 규칙에 따라 부호는 고정된다: 팔굽혀펴기·윗몸일으키기 Δ ≥ 0, 3km Δ ≤ 0, 하중비 Δ = 0. 하중비 Δ 0은 군장 수행능력 충족 여부를 의미하지 않는다.

### 1.6. API 계약 (모듈 1 → 모듈 2)

열 순서와 단위는 고정한다.

```json
{
  "schema_version": "2.0",
  "operation": "goal_minus_now",
  "column_order": ["pushups_2min", "situps_2min", "run_3km_seconds", "load_to_body_weight_ratio"],
  "column_units": ["reps", "reps", "seconds", "ratio"],
  "difference_matrix": [[16, 18, -148, 0]],
  "improvement_columns": ["pushups_2min", "situps_2min", "run_3km_seconds"],
  "load_context": {"combat_load_kg": 15, "load_to_body_weight_ratio": 0.2, "usage": "reference_only"},
  "soldier": {"soldier_id": "SYN-0001", "height_cm": 175, "weight_kg": 75, "bmi": 24.5, "age": 23, "sex": "M", "role": "infantry_rifleman", "synthetic": true},
  "current_records": {"pushups_2min": 48, "situps_2min": 60, "run_3km_seconds": 960},
  "goal_records": {"pushups_2min": 64, "situps_2min": 78, "run_3km_seconds": 812},
  "versions": {"standards": "1.0", "exercise_catalog": "1.0", "plan_rules": "1.0"}
}
```

모듈 2는 이 형식으로 입력을 받으며, 모듈 1은 adapter로 이 형식에 맞춰 보낸다. 모듈 2는 `difference_matrix`가 `goal_records − current_records`와 일치하는지 교차 확인한다.

## 2. 모듈 2: 운동 계획 생성 및 검증

### 2.1. 차이 행렬 해석

| 항목 | 차이값 해석 |
|---|---|
| 팔굽혀펴기·윗몸일으키기 | 양수는 증가가 필요한 횟수 |
| 3km 달리기 | 음수의 절댓값은 단축이 필요한 시간 |
| 세 항목의 0 | 해당 목표 기준 충족 |
| 하중비 | 개선 필요량 분석에서 제외 |

횟수와 시간은 단위가 다르므로 차이값을 합산하거나 숫자 크기만으로 우선순위를 정하지 않는다.

### 2.2. 계획 생성 (Claude)

Claude에는 차이 행렬과 항목별 개선 필요량, 현재·목표 기록, 장병 정보, 전투하중·하중비, 운동 30종 목록, 계획 작성 규칙과 출력 형식을 전달한다.

> 연령별 체력검정 각 종목의 1급 이상 달성을 목표로 하면서, 15kg 군장 훈련 수행에 필요한 체력을 준비하는 8주 운동 계획을 생성한다.

- 30종은 **선택 후보**다. 개인에게 맞는 운동만 골라 주당 3~6개를 배치한다.
- 한 주에 여러 운동을 배치할 수 있고, 같은 운동을 여러 주 반복할 수 있다.
- 계획 행의 열: `주차 / 운동 ID / 주당 실시 횟수 / 세트·횟수 또는 시간 / 보완 대상 / 추천 이유 / 근거 ID`
- 하중비만으로 목표 기록이나 운동량을 결정하지 않는다. 15kg 조건을 모든 운동에 적용하지 않는다.
- 배낭 보행(EX27)과 바벨 백스쿼트(EX09)는 운동 목록에 남겨 두되, 현재 계획 규칙(`excluded_exercises`)으로 **계획에서 제외**한다. 바벨 백스쿼트는 계획에 무게 처방이 없어 제외한다. 군장 준비는 하중 적응 운동(들고 걷기, 계단 오르기)을 최소 4개 주에 넣어 다룬다.
- 3km 개선이 필요하면 3주차부터 매주 고강도 달리기(인터벌·템포런)를 1회 이상 넣는다.
- 마지막 주의 총 세트·총 시간은 직전 주를 넘지 않는다(체력검정 전 부담 조절).
- 매주 회복 운동을 1개 이상 넣는다.
- 팔굽혀펴기·윗몸일으키기의 1세트 횟수는 현재 기록의 일정 비율(가안 0.6) 이하로 한다. 상한 값은 코드가 계산해 Claude에 전달한다.
- 같은 운동의 추천 이유는 주차마다 그 주에 바뀌는 점과 이유를 쓰며, 숫자만 바꾼 같은 문장을 반복하지 않는다.

### 2.3. 운동 목록 (`backend/module2/data/exercises_v1.0.json`)

30종, 6개 분류: 유산소 6, 하체 근력 7, 코어 6, 상체 6, 하중 적응 3, 회복 2. 허용 장비는 맨몸·철봉·평행봉·덤벨·바벨+랙·케틀벨·트레드밀·실내자전거·배낭·줄넘기.

운동별 필드: `exercise_id`, `name`, `category`, `related_tests`(`pushups_2min`/`situps_2min`/`run_3km_seconds`/`load_carriage`/`recovery`), `difficulty`(1~3), `equipment`, `dose`(형식과 허용 범위), `frequency_per_week`(범위), `restrictions`, `evidence_ids`, `grade`, `confirm_needed`.

근거는 `evidence_v1.0.json`에 ID로 관리한다.

### 2.4. 계획 검증 (코드)

| 검증 항목 | 내용 |
|---|---|
| 계획 구조 | 1~8주가 모두 존재하고 각 주에 운동이 배치되었는지 |
| 운동 목록 | 등록된 30종 안에서 선택했는지 |
| 운동량·빈도 | 운동별 허용 범위, 주당 운동 수, 주간 총량 상한·증가율, 마지막 주 총량 ≤ 직전 주, 매주 회복 운동, 팔굽혀펴기·윗몸일으키기 1세트 횟수 상한 |
| 적용 조건 | 주차별 난이도·장비·제한사항 준수, 제외 운동(배낭 보행 EX27, 바벨 백스쿼트 EX09) 미사용 |
| 추천 근거 | 보완 대상·근거 ID가 운동 목록과 일치하는지, 개선 필요 종목이 매주 다뤄지는지, 3km 개선 필요 시 3주차부터 매주 고강도 달리기, 하중 적응 운동 최소 4개 주 |
| 설명 수치 | 추천 이유의 숫자가 전달된 차이값·기록·해당 행의 처방값과 일치하는지, 같은 운동에 숫자만 바꾼 문장을 반복하지 않는지, 어색한 표현이 없는지 |
| 하중 정보 활용 | 하중비를 수행능력 점수로 해석하거나 목표에 가중했는지, 의료 표현("진단", "부상 예측" 등)이 없는지 |

규칙 값은 `backend/module2/data/plan_rules_v1.0.json`에서만 읽는다. 검증 통과는 등록된 규칙 준수를 의미할 뿐, 실제 훈련 효과나 임무 수행능력의 입증이 아니다.

### 2.5. 수정 및 재검증

검증 실패 시 위반한 주차, 운동 ID, 필드, 허용 범위, 위반 사유를 Claude에 전달한다. 수정된 계획은 전체 검증을 다시 수행한다. 최초 생성 이후 수정은 **최대 2회**이며, 한도 내에 통과하지 못하면 미통과 상태와 오류 내역을 반환한다. 재시도 횟수와 통과 판정은 코드가 결정한다.

### 2.6. 최종 출력

장병 정보, 현재·목표 기록 비교표, 항목별 개선 필요량, 전투하중·하중비 참고 정보, 8주 운동 계획, 추천 이유와 근거, 검증 결과, 재생성·수정 이력, 적용 데이터 버전. 화면에 합성 데이터임을 표시한다.

## 3. 구현 완료 기준

- 정상 입력에 대해 데이터 검증부터 최종 계획 출력까지 전체 처리 흐름이 동작한다.
- 동일한 입력과 기준 버전에서 목표 기록 및 차이 행렬이 동일하게 산출된다.
- 차이 행렬의 크기, 열 순서 및 단위가 API 계약과 일치한다.
- 잘못된 입력, 운동 목록 외 항목 및 계획 규칙 위반을 탐지한다.
- 위반 사항 전달, 계획 수정 및 재검증 절차가 동작한다.
- 수정 한도 초과 시 미통과 상태를 반환한다.
- 적용한 목표 기준표, 운동 목록 및 검증 규칙의 버전을 확인할 수 있다.

실제 장병 대상 8주 훈련, 체력 향상 효과 및 15kg 군장 훈련 수행능력 검증은 후속 단계로 구분한다.
