## 실제 호출 및 선택 실행 경로의 확인 범위

작업 환경의 패키지 다운로드가 WinError 10013으로 차단되어 FastAPI·Anthropic 패키지를 새 가상환경에 설치하지 못함. 실제 Claude API 키도 설정하지 않았으므로 유료 API 인증·모델 생성은 실행하지 않음. 사용자 PowerShell에서 `setup.ps1` 실행 후 `.env`에 키를 설정해야 실제 생성이 가능함.

기본 통합 실행은 표준 HTTP 서버로 검증함. 선택 사항인 FastAPI 진입점은 같은 PlanService를 사용하지만, FastAPI 전용 4개 테스트는 이번 환경에서 실행하지 못함. 설치 후 `python -m pytest tests backend/module2/tests -q`로 전체 실행 가능.

이 검증은 소프트웨어 연결과 등록 규칙 준수를 확인하며, 실제 체력 향상이나 군장 수행능력을 검증하지 않음.

## Goal 고정 정책 변경 검증 (API 계약 v2.0.0)

현재 기록보다 좋은 값을 선택하던 max/min 처리를 제거하고, Goal을 연령별 1급 기준값으로 고정했다. 기준 초과 기록의 차이도 0으로 자르지 않는다.

- 목표·군번·DB·HTTP 통합 테스트 22개 재실행 및 통과.
