## Goal 고정 정책 변경 검증 (API 계약 v2.0.0)

현재 기록보다 좋은 값을 선택하던 max/min 처리를 제거하고, Goal을 연령별 1급 기준값으로 고정했다. 기준 초과 기록의 차이도 0으로 자르지 않는다.

- 목표·군번·DB·HTTP 통합 테스트 22개 재실행 및 통과.
- 기준 초과 사례 90회·100회·700초 → Goal 64회·78회·812초, 차이 -26회·-22회·+112초 확인.
- 저장 후 조회 및 모듈 2 수신 검증까지 동일한 Goal·차이 사용 확인.
- 예전 max/min 방식의 Goal과 v1 계약 요청 거부 확인.
- 배치 장병 1,000명 모두 goal_records와 reference_records 일치 확인.
- 원본 합성 데이터와 DB의 현재 기록은 변경하지 않고 계산 결과만 갱신.

이 변경에서 재실행한 테스트는 위 22개이다. 앞서 수행한 생성기·검증기 자체 테스트 13개와는 구분한다.
