# 합성 장병 데이터 생성

파일: `02_generate_synthetic_soldiers.py` (Python 3.10 이상, 이미지 생성에는 Matplotlib 필요)

저장소 루트에서 실행:

```powershell
python backend/module1/02_generate_synthetic_soldiers.py --count 1000 --seed 42
```

기본 출력은 실행한 위치와 관계없이 스크립트 옆 `data/`이다.

| 결과 파일 | 내용 |
| --- | --- |
| synthetic_soldiers.csv | 합성 장병 목록, Excel에서 열 수 있는 UTF-8 BOM CSV |
| synthetic_soldiers.json | 동일 목록의 JSON |
| generation_metadata.json | 출처, 공식 수치, 가정, seed, 생성 연령 분포와 요약 통계 |
| summary_statistics.csv | 나이·키·체중·BMI·체력·하중의 평균, 표준편차, 최솟값, 백분위, 최댓값 |
| age_distribution.csv | 18~29세 각 나이의 인원, 실제 비율과 모델 기대 비율 |
| fitness_distribution.csv | 체력 테스트 시나리오별 인원 및 비율 |

같은 Python 버전, 코드, seed, service-year를 사용하면 같은 레코드가 생성된다.
기존 결과를 갱신할 때는 `--overwrite`, 다른 곳에 저장할 때는 `--output-dir 경로`를 사용한다.

## Matplotlib 이미지 생성

`module1` 폴더에서 한 번 설치한다.

```powershell
python -m pip install -r requirements-plots.txt
```

이미 생성한 데이터는 아래 명령으로 그래프만 만들 수 있다.

```powershell
python .\02_generate_synthetic_soldiers.py --plots-only
```

그림을 다시 만들 때는 `--plots-only --overwrite`를 사용한다.
이 모드는 `data/synthetic_soldiers.json`과 `generation_metadata.json`을 읽으며
원본 JSON·CSV·통계표를 다시 생성하거나 변경하지 않는다.
`--count`, `--seed`는 재생성하지 않는 이 모드에서 사용하지 않는다.
현재 데이터의 생성 설정을 비교 기준으로 사용하고, 메타데이터가 없으면 실제 분포만 그린다.
입력 JSON의 수치·필수 필드·연령 범위와 메타데이터의 인원수를 확인한다.

새 데이터를 생성하는 기본 실행에서도 PNG 6장을 자동 저장한다.

```powershell
python .\02_generate_synthetic_soldiers.py --count 1000 --seed 42 --overwrite
```

위 명령의 `--overwrite`는 데이터와 그래프 모두를 갱신한다.
Matplotlib 없이 기존의 표만 만들려면 `--no-plots`를 사용한다.

| 이미지 (`data/plots/`) | 내용 |

| 01_age_distribution.png | 나이별 실제 비율 막대와 저장된 모델 기대 비율 비교선 |
| 02_body_distributions.png | 키·체중·BMI 히스토그램, 평균·중앙값·표준편차 |
| 03_fitness_distributions.png | 팔굽혀펴기·윗몸일으키기·3km 기록 히스토그램 |
| 04_height_weight.png | BMI를 색으로 표현한 키–체중 산점도와 생성 표본의 상관계수 |
| 05_fitness_scenarios.png | 테스트 시나리오별 인원·비율 |

- 창을 띄우지 않고 PNG로 저장하며, 이미지 해상도는 180dpi이다.
- 폰트 설치에 따른 한글 깨짐을 피하도록 그래프 표기는 영어로 통일했다.
- 그래프의 3km 기록은 보기 쉽게 **분 단위**로 변환한다. 원본 JSON/CSV는 계속 **초 단위**다.
- 연령 비교선은 실제 데이터 생성 시점의 모델 설정이며, 공식 원표에 없는 구간 분할 가정도 포함한다.
- 산점도의 상관계수는 생성된 데이터에서 계산한 값이며, 실측 장병 상관관계가 아니다.
- 산점도는 10,000점이 넘으면 일정 간격으로 표시할 점만 줄인다. 통계와 상관계수는 전체 표본으로 계산한다.
- 표준편차는 모집단 표준편차를 사용한다. 한 명만 있는 경우에도 그래프를 만들며 상관계수는 표시하지 않는다.
- 현재 버전은 2분 체력 기록을 새로 합성한다. 이전 1분 기록을 비례 환산하지 않는다.
- 데이터 생성과 그림 저장 함수는 모두 `02_generate_synthetic_soldiers.py` 안에 들어 있다. Python 파일 하나만 실행한다.

## 이 방식으로 만드는 이유

이번 단계의 목적은 가상의 장병 정보를 다음 모듈에 전달하여 목표·차이 계산과 추천 입력 흐름을 확인하는 것이다.
실제 장병의 신체·체력 분포를 완전히 재현하거나 모델을 학습할 정답 데이터를 만드는 단계는 아니다.

| 결정 | 이유 | 근거 수준 |
| --- | --- | --- |
| 최소 연령 18세 | 모집병 지원 가능 연령부터 사례를 포함 | 병무청 안내 |
| 최대 연령 29세 | 사용자가 정한 이번 시제품의 범위 | 프로젝트 설정, 법적 상한 아님 |
| 연령별 가중 추출 | 균등 추출로 고연령 사례가 과도하게 많아지는 것을 피하고 입영자 구성을 참고 | 공식 입영 통계 + 구간 분할 가정 |
| 2024년 분포에 고정 | 확인한 원문 수치로 재현 가능한 첫 버전을 구성 | 기준 연도를 명시, 최신 통계라는 주장 없음 |
| 키·체중·BMI를 수식으로 연결 | 세 값을 독립 생성했을 때 생기는 BMI 불일치를 방지 | BMI 정의 + 신체 생성 모델 가정 |
| 신체와 체력 생성 분리 | 확보한 신체 자료로 체력 수행능력을 추정할 근거가 부족 | 실증 관계를 임의로 주장하지 않는 설계 |
| 여러 체력 시나리오 | 팔굽혀펴기·윗몸일으키기·달리기 기록 차이 등 다른 추천 입력을 시험 | 테스트 설계 |
| seed 저장 | 오류가 난 동일 사례를 다시 만들기 위해 | 재현성 |
| CSV와 JSON 동시 출력 | 사람이 표로 검토하고 후속 모듈에서도 읽기 위해 | 구현 선택 |
| 메타데이터·통계표 동시 출력 | 근거와 가정, 생성 결과를 함께 검토하기 위해 | 검증 가능성 |

## 연령 기준

18~29세, 병역법의 연나이(기준 연도 - 출생 연도)를 사용한다.
이는 생일 기준 만 나이가 아니다. 29세는 이번 시제품의 상한이며 법적 입영 상한을 뜻하지 않는다.
모집병은 18세부터 지원 가능하다.

- [병무청 연령 및 18세 지원 안내](https://www.mma.go.kr/board/boardView.do?gesipan_id=317&gsgeul_no=1501415&mc=mma0002306)
- [2024 병무통계연보](https://mma.go.kr/download/ebook/2024_bmtgyb_1.pdf): 표 2-1-5, 인쇄 125쪽 / 표 2-3-3, 인쇄 141쪽

2024년 징집병 83,393명과 모집병 102,473명, 총 185,866명의 원문 수치를 사용한다.
이를 같은 구간으로 합산한 값은 다음과 같다.

| 연령 | 인원 | 비율 |
| --- | ---: | ---: |
| 18세 | 559 | 0.301% |
| 19세 | 22,904 | 12.323% |
| 20~22세 | 149,053 | 80.194% |
| 23세 이상 | 13,350 | 7.183% |

18~22세 비중은 약 92.8%이다. 이는 입영자 통계이며 현재 복무 중인 보병 소총수의 실측 분포가 아니다.
2025년 자료도 공개되어 있으나 이 초기 버전은 원문 수치를 확인한 2024년에 고정한다.

한 살 단위가 있는 징집병 19~24세는 그대로 반영한다.
모집병 20~22세는 세 나이에 균등 배분한다.
모집병 23세 이상, 징집병 25세 이상은 각각 23~29세와 25~29세에 균등 배분한다.
**묶인 구간의 균등 배분 및 30세 이상을 별도 분리하지 않는 처리는 시연용 가정이다.**
코드는 이 가중치로 무작위 추출하므로 생성 표본의 실제 비율에는 오차가 생긴다.
이 분포를 현역 소총수에 대용한다는 가정도 결과 메타데이터에 남긴다.

### 한 살 단위 가중치를 만드는 계산

원래 자료의 자세한 구간을 가능한 한 유지한다.

- 18세: 모집병 559명.
- 19세: 징집병 5,824 + 모집병 17,080 = 22,904명.
- 20세: 징집병 50,046 + 모집병 20~22세 78,060 / 3 = 76,066명 상당 가중치.
- 21세: 16,251 + 78,060 / 3 = 42,271명 상당 가중치.
- 22세: 4,696 + 78,060 / 3 = 30,716명 상당 가중치.
- 23세: 징집병 2,321 + 모집병 23세 이상 6,774 / 7.
- 24세: 징집병 1,445 + 6,774 / 7.
- 25~29세 각각: 징집병 25세 이상 2,810 / 5 + 6,774 / 7.

각 가중치를 185,866으로 나누어 추출 확률로 사용한다.
분할 이후의 소수 인원은 모델 계산용 가중치이며 실측 인원수가 아니다.
**이 가정을 적용한 생성 모델에서는 18~23세의 기대 비중이 약 94.59%이다.**
이는 공식 표에서 직접 읽은 18~23세 비율이 아니며, 공식 구간으로 정확히 합산 가능한 값은 18~22세 약 92.82%이다.

원문 인원표는 `data/reference_age_counts_2024.csv`에 별도로 저장한다.
해당 파일은 공식 집계 수치의 전사본이며 합성 장병 목록이 아니다.

## 신체·체력 데이터의 근거 범위

[한국인인체치수조사 공식 보고서](https://mods.go.kr/boardDownload.es?bid=12030&list_no=422680&seq=1)의
2020~2021년 남성 평균을 사용한다(인쇄 222쪽 키, 226쪽 BMI).

| 기준 구간 | 평균 키(cm) | 평균 BMI |
| --- | ---: | ---: |
| 20~24세 | 174.6 | 23.8 |
| 25~29세 | 174.1 | 24.3 |

확보된 것은 위 평균값이다. **공식 신체 분포 전체를 확보한 상태는 아니다.**
18~19세에는 20~24세 평균을 임시 대용한다. 연나이를 신체 통계의 연령 구간에 직접 대응하는 것도 근사이다.

시연용으로 키의 표준편차 5.5cm, 잠재 BMI의 표준편차 3.5를 설정했다.
키는 정규분포, 잠재 BMI는 로그정규분포에서 범위를 벗어나는 값을 재추출한다.
두 변수는 연령 구간 내 독립으로 가정하고 `체중 = 잠재 BMI × 키(m)^2`로 계산한다.
최종 BMI는 반올림하여 저장한 키와 체중으로 다시 계산한다.
키-체중 상관관계를 실측 자료에 맞췄다는 뜻은 아니다. 표준편차와 공동분포를 확보하면 교체해야 한다.

체력은 체격과 독립인 6가지 테스트 시나리오를 동일 확률로 선택한다.
각 시나리오의 운동 기록, 변동 폭과 범위는 공식 체력 통계가 아닌 시연용 값이다.
성별은 male, 보직은 infantry_rifleman, 전투하중은 15kg으로 고정한다.
기초 체력 기록은 무부하 가상 기록이며 15kg을 착용한 측정값이 아니다.

## 통계표를 읽는 방법

`summary_statistics.csv`는 실제로 생성한 전체 표본을 대상으로 집계한다.
표준편차는 분모 N인 모집단 표준편차이며 열 이름을 `std_population`으로 표시한다.
P05/P25/P75/P95는 정렬한 값의 위치 (N-1)×p에서 선형 보간한다.
표본이 한 명인 경우 표준편차는 0이고 모든 백분위가 그 관측값이다.

`age_distribution.csv`는 관측되지 않은 나이도 인원 0으로 포함한다.
`model_expected_percent`는 위 구간 분할 가정이 포함된 생성 확률이다.
공식 한 살 단위 실측 비율로 해석하면 안 된다.
`actual_percent`는 실제 생성된 표본에서 계산하므로 seed와 표본 수에 따라 달라진다.

`fitness_distribution.csv`는 시연용 6개 시나리오의 구성비를 확인하는 표다.
실제 군인의 체력 수준별 비율을 뜻하지 않는다.

평균이 비슷한 것만으로 현실성이 검증되지는 않는다.
다음 단계에서는 신체 표준편차·백분위·공동분포를 확보하여 체중과 BMI의 분포도 대조해야 한다.
현재 표는 생성 결과를 점검하는 자료이며 체력 향상 효과나 의학적 적합성 평가가 아니다.

## 후속 보완 항목

1. 18~19세의 신체 평균과 분포를 별도로 확보하여 대용값 교체.
2. 같은 조사에서 키·체중/BMI의 표준편차, 백분위와 공동분포 확보.
3. 23세 이상 및 25세 이상 연령 구간의 상세 자료 확보 시 균등 분할 교체.
4. 입영자 분포와 현역 소총수 분포를 구분할 수 있는 자료가 있으면 연령 가중치 교체.
5. 입력 체력과 동일한 측정 방식(2분, 3km)의 근거 자료 확보 시 시연용 기록 규칙 교체.

## 군번 및 2분 측정 조건

군번 필드 `soldier_id`는 `YY-NNNNNNNN` 형식의 고유 조회 키다. 기본값은 `26-00000001`부터 시작한다. `--service-year 2022`를 지정하면 `22-00000001`부터 생성한다. 가상 군번이며 실제 입대 이력과의 관계를 생성하지 않는다.

현재 체력 필드는 `pushups_2min`, `situps_2min`, `run_3km_seconds`이다. 120초·3000m·무군장 측정 조건을 각 레코드에 명시한다. 체력 시나리오와 범위는 `generation_metadata.json`을 따른다. 1분 기록은 검증기에서 거부한다. 웹·DB·API 사용법은 [프로젝트 README](../../README.md)를 참고한다.
